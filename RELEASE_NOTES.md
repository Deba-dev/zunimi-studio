## Zunimi Stream+ 0.5.4 (preview)

Move the window again, in every window mode.

**Install:** download **ZunimiStudio-Setup.exe** below and run it. Already on 0.5? The app offers this update by itself. If Windows SmartScreen warns you, click **More info > Run anyway** (the installer isn't code-signed yet).

### Fixed
- **Windowed mode always has its title bar:** a window size saved while in fullscreen could bring Windowed mode back without a title bar, so the window could not be dragged.
- **Move from Borderless and Fullscreen:** touch the top edge of the screen and drag the new grip (six dots, left of minimize). Zunimi pops out into a normal window that follows the mouse.
